# ESS 배터리 수명 예측

초기 100 사이클의 충·방전 데이터만으로 배터리 수명(Cycle Life)을 예측해, ESS 배터리의 교체 시점을 사전에 계획할 수 있는지 확인한다.


## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12)
- 평가 데이터 : Batch 2 (2018-02-20) / 추가 검증 : Batch 3 (2018-04-12)
- 태스크 : Regression (Cycle Life 예측, 타깃 `log10(cycle_life)`)

## Modeling

### 피처 엔지니어링 전략
- 핵심 피처 : `dq_logvar` — 사이클 100과 사이클 10의 방전 곡선 차이 ΔQ(V)의 분산(log10). EDA에서 세 배치 모두 부호가 일관되었고(ρ −0.72~−0.85), 같은 셀 안의 차이라 배치마다 다른 `Qdlin` 시작점이 상쇄된다.
- 시도했지만 채택하지 않은 피처 : 전압 구간별 ΔQ 분산(파생변수), `QD_slope`·`IR`·`Tavg`, `C1`·`switch`. Batch 1 CV에서 1%p 이상 개선되지 않았다(`results/experiment_log.md`).
- 제외한 피처 : `dq_logmean`·`dq_logmin`(`dq_logvar`와 중복, ρ≈0.97), `dq_skew`·`dq_kurt`, `Tmax`, `chargetime`, `QD_mean`, `avgC`·`C2`, `newstructure` (근거는 EDA 참고).
- 전처리 : 결측 대치(`IR`)와 스케일링은 학습 데이터로만 fit하는 Pipeline 안에서 수행하고, 타깃은 `log10`으로 학습한다.

### 모델 선택 및 근거
- 후보 모델 : Elastic Net, Ridge, PLS, Random Forest, Gradient Boosting, XGBoost, LightGBM, Gaussian Process (기준선: 평균 예측). XGBoost·LightGBM은 OpenMP 런타임이 필요하다(macOS는 `brew install libomp`). 환경 설정이 늦어 처음 비교에서는 빠졌고, 추가해서 같은 기준으로 다시 비교했지만 선택 결과는 같았다. 모델 예측을 평균하는 앙상블 4종도 같은 기준으로 비교했지만 Train CV가 단일 선형 모델보다 높아(7.83~9.21% vs 7.40%) 채택하지 않았다.
- 최종 모델 : `dq_logvar` + Elastic Net (`alpha=0.01`, `l1_ratio=0.5`)
- 선택 이유 : Batch 1 Train CV MAPE가 선형 모델 7.2~7.4%로 가장 낮고(평균 예측 19.2%, 트리·부스팅·GP 9.2~11.5%), 어떤 추가 피처도 1%p 이상 개선하지 못해 가장 단순한 조합을 택했다. 선택에는 Batch 1의 CV만 사용했고 Batch 2는 사용하지 않았다. Hold-out(11셀)은 극단 셀 3개 때문에 선형 모델 약 21~24%, 트리·부스팅·GP 약 7~11%로 갈렸지만 표본이 작아 참고만 했다.
- 사전 전략과의 대응(전략 → 구현 반영)은 `notebooks/03_modeling.ipynb` 9번 섹션에 정리했다.


## 성능 결과

| 구분 | MAPE (%) | 비고 |
| --- | --- | --- |
| Train (Batch 1 CV) | 7.40 | 프로토콜 단위 5-fold 평균 |
| Valid (Batch 1 Hold-out) | 21.20 | 프로토콜 단위 Hold-out 11셀. 극단 셀 3개를 빼면 10.60 |
| Test (Batch 2) | 38.32 | 평균 예측 67.09. 평균 편향 +36.2% (39셀 중 34셀 과대예측) |
| Gap (Train-Valid) | +13.80 | (+) : 과적합 의심 |
| Gap (Valid-Test) | +17.12 | (+) : 배치간 일반화 저하 의심 |
| Gap (Target-Test) | +29.22 | Target : 원논문 9.1% |
| Test (Batch 3) | 13.98 | 추가 검증. 평균 예측 21.15. 평균 편향 −8.0% |
| Gap (Batch2-Batch3) | −24.34 | Batch 3 − Batch 2. (−) : Batch 3의 오차가 더 작음 |
| Gap (Target-Test) [Batch 3] | +4.88 | Batch 3 기준 |

(Gap은 오차가 커질수록 (+)이다. 최종 모델 : `dq_logvar` + Elastic Net, Test는 Batch 1 전체(46셀)로 학습한 모델로 한 번만 평가했다.)

- **성능 지표** : 회귀이므로 MAPE (%). 원논문 성능은 Regression 9.1%(MAPE)이다.
- **데이터 분할과 파이프라인** : Batch 1(46셀)을 프로토콜 단위로 학습 35셀 / Hold-out 11셀로 나누고(겹침 0), 결측 대치·스케일링·`log10` 타깃 변환은 Pipeline 안에서 학습 데이터로만 fit한다. Batch 2는 최종 모델 확정(`results/experiment_log.md`에 평가 전 기록) 뒤 한 번만 평가했다. 상세는 `notebooks/03_modeling.ipynb` 0·1번 섹션.
- **Train (Batch 1 CV)** : Batch 1 학습 셀 안에서 프로토콜 단위로 묶어 나눈 5-fold(GroupKFold) 교차검증의 평균 성능.
- **Valid (Batch 1 Hold-out)** : 프로토콜 단위로 따로 떼어 둔 Batch 1의 11셀로 평가한 성능.
- **Valid를 CV가 아닌 Hold-out으로 쓴 이유** :
	- 배터리 데이터는 셀 단위로 독립적이고, 셀마다 서로 다른 충전 프로토콜(C-rate)로 실험된다.
	- 이때 CV를 그대로 적용하면 같은 프로토콜의 셀이 학습과 검증에 나뉘어 들어가 데이터 누수(leakage) 위험이 남는다.
	- Hold-out은 프로토콜(셀) 단위 분리를 명확히 보장하고, 배치 간 일반화를 평가하는 이번 프로젝트 구조에도 더 적합하다. (Train의 CV는 같은 프로토콜을 한 폴드에 묶는 GroupKFold라 누수가 없다.)
- **원논문 대비 (Gap Target-Test, Batch 2 기준)** : 원논문 Regression 9.1%(MAPE)에 비해 Batch 2 Test는 38.32%로 오차가 **29.22%p(약 4.2배)** 크다. 식으로는 Target − Test = −29.22%p이며, 위 표는 다른 Gap과 부호를 맞추려고 오차가 커질수록 (+)가 되게 Test − Target = +29.22로 적었다. Classification 기준(원논문 1-Accuracy 4.9%)은 회귀를 택해 해당하지 않는다.
- **사후 개선 (Test 평가 이후의 시도, 독립 검증 아님)** : 라벨 불확실 8셀을 학습에서 정리하고 Ridge로 학습하면 Batch 2 29.16% / Batch 3 12.18%(Gap Target-Test +20.06)로 낮아진다. 개선의 대부분은 라벨 정리 효과다. 반면 Batch 1 안에서 배치 이동을 흉내 낸 검증으로 고른 모델(핵심 + 충전 피처 + Ridge)은 Batch 2 43.92% / Batch 3 16.24%로 공식 결과(38.32% / 13.98%)보다 오히려 나빠졌다. 충전 피처(`C1`, `switch`)가 배치를 넘어 일반화되지 않았고, 한 배치 안의 검증으로는 배치 간 일반화를 고르기 어렵다는 뜻이다. 공식 결과는 38.32%로 그대로 두고, 사후 시도는 `results/experiment_log.md` 5·6번에 기록했다.
- **Train → Valid (+13.80)** : 과적합처럼 보이지만 Hold-out 11셀 중 3셀(b1c0·1·2, 수명 약 1,180)이 원인이다. 이 셀들은 ΔQ 분산이 학습 범위 밖이고 수명 라벨도 검증되지 않는 셀이라, 라벨 불확실 8셀을 빼면 Train 8.15 / Valid 10.60으로 Gap이 +2.45로 줄어든다. Valid는 표본이 작아 판단 근거로 약하다.
- **Valid → Test (+17.12)** : Batch 2에서 오차가 크게 늘었다. 평균 예측(67.09%)보다는 크게 낫지만, 배치가 바뀌면 일반화가 크게 떨어진다.
- **Target → Test (+29.22)** : 원논문 9.1%에 크게 못 미친다. 이 데이터에서는 과제 안내와 달리 Batch 1과 Batch 2의 수명 분포가 크게 다르다(Batch 2 셀의 77%가 Batch 1 수명 범위 밖). Batch 2 안에서도 신규구조 셀 9개는 12.8%로 목표에 가깝다.
- **Batch 3이 Batch 2보다 낫다(13.98 vs 38.32)** : Batch 3의 수명이 더 길고 다르지만 오차는 더 작다. 배치 간 수명 분포 차이보다 "같은 ΔQ 분산에서 수명이 얼마나 짧아지는가"의 차이가 성능을 좌우한다.
- **Gap (Batch2-Batch3) −24.34와 피처의 배치 과적합 가능성** : Batch 2와 Batch 3의 오차가 24.34%p 벌어졌다. 피처(`dq_logvar`)가 Batch 1에 과적합되었는지를 근거별로 나눠 본다.
	- 과적합이 아니라는 근거 : 같은 모델이 Batch 3(13.98%)과 Batch 2의 신규구조 셀 9개(12.8%)에서는 비슷하게 맞는다. `dq_logvar`와 수명의 관계가 배치를 넘어 유지되는 셀 집단이 있다.
	- 일반화되지 않는 근거 : Batch 2 기존구조 셀 30개에서만 +46% 과대예측한다(학습 범위 안의 셀도 50.3%). 이 집단에서는 같은 ΔQ 분산에서 수명이 더 짧아 관계가 이동한다.
	- 해석 : 피처 자체가 Batch 1에 과적합되었다기보다, **Batch 1에 없던 셀 집단(기존구조)에서는 피처와 수명의 관계가 달라** 일반화되지 않는 것으로 본다. 반면 특정 배치에 맞춰진 피처의 과적합은 사후 시도에서 직접 확인됐다. 충전 피처(`C1`, `switch`)를 추가하면 Batch 1 검증은 좋아졌지만 Batch 2 43.92%, Batch 3 16.24%로 나빠졌다.


## 오류 분석
- 모델이 가장 크게 틀린 셀의 공통점
	- Batch 2에서 가장 크게 틀린 8셀은 모두 **기존구조 셀**(수명 392~452)이고, 전부 과대예측이다(+52~+89%). 기존구조 30셀의 MAPE는 46.0%(전부 과대예측), 신규구조 9셀은 12.8%(편향 +3.7%)다. Batch 2 오차의 대부분이 기존구조 셀에서 나온다.
	- 이 셀들은 같은 프로토콜의 신규구조 셀보다 수명이 약 절반인데, ΔQ 분산은 학습 범위 안팎에 걸쳐 있다.
	- Batch 3에서는 학습 최대 수명(1,227)을 넘는 9셀의 MAPE가 29.8%(전부 과소예측)이고, 범위 이내 35셀은 9.9%다. 장수명 셀을 짧게 예측한다.
- 원인 가설 및 개선 방향
	- 가설 1 (외삽) : 기존구조 셀 중 ΔQ 분산이 Batch 1 학습 범위 **안**인 18셀도 MAPE가 50.3%다. 외삽만으로는 설명되지 않는다.
	- 가설 2 (관계의 이동) : 같은 ΔQ 분산에서 Batch 2 기존구조 셀의 수명이 Batch 1보다 짧다(예: Batch 1에서 ΔQ 분산이 가장 큰 셀들은 수명 534~617, Batch 2 기존구조 셀은 비슷한 분산에서 수명 중앙값 451). 셀 구조나 제작 조건의 차이로 ΔQ 분산과 수명의 관계가 이동한 것으로 보이며, 이 데이터만으로 원인을 확정할 수는 없다.
	- 학습 라벨의 영향 : 라벨 불확실 8셀을 학습에서 빼면 Batch 2 MAPE가 38.32 → 30.31로 낮아진다. 라벨 품질이 선형 관계의 기울기를 바꾼다.
	- 참고 : 참고용 비교군의 Batch 2 MAPE는 Gaussian Process 28.87, LightGBM 32.21, Random Forest 33.48, Gradient Boosting 33.50, XGBoost 35.00으로 모두 최종 모델(38.32)보다 낮았다(평가 전에 정해 둔 비교군은 Gaussian Process, Gradient Boosting, Random Forest이고 XGBoost·LightGBM과 앙상블은 평가 뒤에 추가했다)(Batch 3은 12.58~15.48로 최종 모델 13.98과 비슷). Batch 1 CV에서는 선형 모델이 앞섰던 순위가 Batch 2에서는 뒤집혔다. Batch 1 안의 CV가 배치 이동을 반영하지 못한다는 뜻이다. 앙상블(평균)도 Batch 2 33.07~33.92, Batch 3 12.14~13.79로 최종 모델보다 낮았다. 이 비교는 모두 참고이며 결과를 본 뒤에도 최종 모델은 바꾸지 않았다.
	- 개선 방향 : (1) 구조·배치 차이를 설명하는 정보를 입력에 넣거나, 구조별로 관계가 다름을 모델에 반영한다. (2) 장수명·단수명 끝에서 포화되는 관계를 다룰 수 있도록 비선형 모델이나 변환을 검토한다. (3) 라벨 불확실 셀의 처리 규칙을 학습 전에 정한다. (4) 배치 이동을 반영하는 검증(배치 단위 교차검증)으로 모델을 고른다.


## ESS 도메인 해석
- 이 모델을 실제 BESS에 적용한다면 어떤 의사결정에 활용 가능한가?
	- **셀·모듈 조기 선별** : 초기 100 사이클의 ΔQ(V) 분산으로 수명이 짧을 위험이 큰 셀을 가려내고, 교체 계획과 보증 기준을 정하는 데 쓸 수 있다. 수치 자체보다 셀 간 순위와 구간이 더 믿을 만하다(CV 7.4%, 같은 조건으로 보이는 Batch 2 신규구조 12.8%, Batch 3 13.98%).
	- **예측이 틀리는 방향이 중요하다** : Batch 2 기존구조 셀은 실제보다 오래 갈 것으로 +46% 과대예측했다. 이는 교체를 늦춰 예기치 못한 중단과 피크 대응 실패로 이어질 수 있는 위험한 방향이다. 실제로 쓴다면 예측값을 그대로 쓰지 않고 보수적으로 낮춘 하한이나 예측 구간을 써야 한다.
- 어떤 한계가 있으며, 실 배포를 위해 추가로 필요한 것은 무엇인가?
	- 한계 : 실험실에서 정해진 프로토콜로 충·방전한 46셀(Batch 1)로 학습했고, 제작 조건이 다른 셀(Batch 2 기존구조)에는 일반화되지 않았다. ΔQ(V)는 사이클 10과 100의 방전 곡선 전체가 필요한데, 실제 BESS는 부분 충·방전이 많아 같은 곡선을 얻기 어려울 수 있다.
	- 개발상 한계 : ① 배치 간 일반화(기존구조 셀 +46% 과대예측) ② 표본 크기(46셀, Hold-out 11셀) ③ Batch 1 내부 CV·Hold-out이 배치 이동을 반영하지 못함 ④ 라벨 불확실 8셀(제외 시 Batch 2 38.32 → 30.31) ⑤ 피처 선별 EDA에서 Batch 2·3을 함께 봄(모델 선택은 Batch 1 CV만 썼지만 완전한 블라인드는 아님) ⑥ 미구현: Leave-One-Batch-Out, 예측 구간(부트스트랩) ⑦ 배치 이동을 흉내 낸 Batch 1 검증도 실제 배치 이동을 반영하지 못함(검증은 개선됐지만 Test는 악화)
	- 실 배포를 위해 필요한 것 : (1) 실제 운영 데이터로 성능을 검증하는 Live Test (2) 제조 로트·구조 정보 같은 메타데이터와 배치 단위 검증 (3) 예측 구간 제공 (4) Model Drift와 Data Drift(입력 분포 변화)를 정기적으로 점검하고, 성능이 기준 이하로 떨어질 때 재학습하는 규칙 (5) 부분 방전에서도 계산할 수 있는 피처로의 확장.
